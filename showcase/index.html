Icons

WebTUI ships without an icon set, but pairs cleanly with Hugeicons. Add the stylesheet, then use any icon as <i class="hgi-stroke hgi-NAME"></i>. Inherits color and font-size.

Setup
<link rel="stylesheet" href="https://use.hugeicons.com/font/icons.css">
<i class="hgi-stroke hgi-home-01"></i>
Variants — stroke / solid / twotone / duotone / sharp / bulk
stroke solid twotone duotone sharp bulk
Sizes — controlled by font-size
Color — inherits currentColor

    Tilt (3D)

    3D rotation responding to mouse position. CSS provides perspective and spring transition; a small JS handler updates --tilt-x / --tilt-y custom properties from cursor coordinates. Customize via data-tilt-max (default 12deg).

    Hover the cards — rotation factor varies by size-

    Live Audio

    Mic capture with frequency-bar visualization. Click to start, click again to stop. The CSS component provides the chrome and bar styles; a small JS handler in the showcase wires navigator.mediaDevices.getUserMedia to the bars' --v custom property.

    Click the mic — your browser will prompt for microphone access
